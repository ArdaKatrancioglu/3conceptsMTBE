# Care Compass — UI concept

A clickable React prototype for a personal care overview after a family doctor visit. All patient details and actions are fictional; the prototype has no backend and stores no data.

## Run locally

```bash
npm install
npm run dev
```

Vite will show a local URL. For a presentation, `npm run build` creates a static production version in `dist/`.

## Interactive elements

- Navigate between Overview, My care, Appointments, and Messages
- Scroll to the visit summary
- Mark items in the day plan as complete
- Switch between patient and clinician views using the control in the sidebar
- Sample actions show a short confirmation on screen

The interface is in English and uses a fictional migraine consultation as its example.
