# Concept 2 — GP dictation tool

A focused dictation app concept for general practice. It captures a GP dictation, creates an editable structured note, and sends the clinician approved note to the practice HIS.

The concept addresses feedback that current dictation tools can be unreliable. It shows the app's own capture and review interface, plus a destination for the practice's existing HIS. It does not recreate the full practice environment.

This is a frontend prototype. It uses sample content and simulated recording, transcription, note generation, and HIS delivery. It has no microphone, AI, backend, or live HIS connection.

## Run

From the project root, run `npm run dev` and open `/concept-2`.
